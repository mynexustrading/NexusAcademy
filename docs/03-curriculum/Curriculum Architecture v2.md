# **Nexus Academy Curriculum Architecture v2**

### **Version 2.0 Draft**

### **Based on Product Architecture v1 \+ Curriculum Validation Summary v1**

---

# **1\. Core Principle**

Curriculum 不再以：

Stage  
↓  
Module  
↓  
Lesson

设计。

---

Curriculum v2 改为：

Identity  
↓  
Capability  
↓  
Stage  
↓  
Module  
↓  
Lesson  
↓  
Evidence

---

这是整个 Nexus Academy 和传统 LMS 最大差异。

---

# **2\. Curriculum Architecture Hierarchy**

Nexus Academy

├── Identity Layer  
│  
├── Capability Layer  
│  
├── Curriculum Layer  
│  
├── Execution Layer  
│  
└── Verification Layer
