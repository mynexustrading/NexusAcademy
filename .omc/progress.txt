## Ralph Session Progress

### Task
Bootstrap Next.js app in NexusAcademy/ using pnpm create next-app@latest with TypeScript, ESLint, Tailwind, App Router, src-dir, @/* import alias.

### Learnings
1. Directory name "NexusAcademy" violates npm naming (capital letters). Workaround: scaffold into a lowercase sibling dir then rsync files up.
2. pnpm 11.x blocks build scripts by default. Fix: set `allowBuilds.sharp: true` and `allowBuilds.unrs-resolver: true` in pnpm-workspace.yaml (NOT in package.json "pnpm" field — that is deprecated in pnpm 11).
3. Tailwind v4 does NOT use tailwind.config.ts. Configuration lives in postcss.config.mjs and CSS imports. This is expected behavior, not missing config.
